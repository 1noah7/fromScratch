From Scratch and its Windows launcher source are BSD-2-Clause; see licenses/.
The launcher is built with Microsoft's Windows .NET Framework compiler and
uses the .NET Framework 4.x already included with Windows 10/11. No third-party
launcher executable, .NET SDK or separate .NET installer is distributed.

lib/ contains the unchanged From Scratch plugin/bootstrap and unmodified
RuneLite Maven artifacts with their normal runtime dependencies. These are
separate JARs, not a modified or shaded RuneLite client. No JUnit, preview
classes, tests, credentials or progression files are included.
DEPENDENCIES.json records their exact coordinates and SHA-256 hashes.
Embedded upstream license/NOTICE files remain intact in each JAR.
RuneLite BSD-2-Clause: https://github.com/runelite/runelite/blob/master/LICENSE

runtime/ is unmodified Eclipse Temurin Windows x64 JRE 11.0.32.1+1.
Its complete legal/ tree, release metadata and upstream notices are retained.
OpenJDK's GPLv2 and Classpath Exception and per-component notices apply;
the runtime is not relicensed under From Scratch's BSD license.
Official release and corresponding source:
https://github.com/adoptium/temurin11-binaries/releases/tag/jdk-11.0.32.1%2B1
https://github.com/adoptium/temurin11-binaries/releases/download/jdk-11.0.32.1%2B1/OpenJDK11U-jdk-sources_11.0.32.1_1.tar.gz
The pinned binary archive checksum/source URL are in native-build.json.
